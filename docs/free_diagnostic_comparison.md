# 무료 진단 문항 수 비교 분석: 16문항 vs 7문항

## 핵심 전제

> **무료 진단의 두 가지 조건:**
> 1. 사용자가 "내 경력 가치가 어느 정도구나"를 **실감**해야 한다
> 2. 동시에 "이건 무료로는 완결되지 않는구나"를 **느껴야** 한다
>
> → 이 두 조건의 균형이 유료 전환의 핵심

---

## 1. 현재 16문항 분석

### 구조

| 카테고리 | 질문 수 | 커버 영역 |
|---------|--------|----------|
| 정체성 (identity) | 2개 (Q1, Q2) | 직함 없는 자기 정의, 자랑스러운 순간 |
| 핵심 가치 (values) | 2개 (Q4, Q5) | 선택 기준, 반복 태도 |
| 강점 (strength) | 3개 (Q3, Q8, Q9) | 전문 영역, 도움 요청 영역, 자연스러운 해결 |
| 스토리 (story) | 2개 (Q6, Q10) | 전환점, 실패에서 배운 것 |
| 타깃 (target) | 3개 (Q7, Q11, Q13) | 돕고 싶은 사람, 에너지 대상, 구체적 상황 |
| 채널 (channel) | 2개 (Q12, Q14) | 편한 표현 채널, 대표 채널 |
| WHY (why) | 2개 (Q15, Q16) | 한 문장 표현, 궁극적 이유 |

### 장점

| # | 장점 | 설명 |
|---|------|------|
| 1 | **진단 깊이가 깊다** | 7개 카테고리 × 2~3문항으로 각 영역을 교차 검증. 한 질문에서 놓친 것을 다른 질문이 보완 |
| 2 | **5차원 결과가 설득력 있다** | 정체성 언어 / 핵심 가치 / 전문성 포지셔닝 / 타깃 명확도 / 시장 진입 자산 — 5개 축 결과가 풍부 |
| 3 | **"무료인데 이 정도까지?"라는 WOW** | 16문항을 다 답하고 나면 "이렇게까지 분석해주다니"라는 놀라움이 큼 |
| 4 | **유료와의 차별화가 명확** | 무료 16문항 vs 유료 42문항 — 수치적으로 "더 깊은 진단"이 자연스럽게 느껴짐 |
| 5 | **답변 데이터가 풍부** | AI 분석 시 더 많은 텍스트 → 더 정교한 패턴 추출 → 더 정확한 결과 |

### 단점

| # | 단점 | 심각도 | 설명 |
|---|------|--------|------|
| 1 | **이탈률이 높다** | 🔴 치명적 | 16문항 × 각 1분 = **최소 16~20분 소요**. 5060 타깃은 디지털 피로도가 높아 중간 이탈 가능성 매우 높음 |
| 2 | **"무료인데 왜 이렇게 많아?"** | 🟠 높음 | 16개 질문을 보는 순간 부담감. 특히 Q12~Q16쯤 되면 답변 품질이 급격히 떨어짐 |
| 3 | **완료율 50% 미만 예상** | 🔴 치명적 | 이메일을 마지막에 수집하므로, 이탈 시 리드조차 못 얻음 |
| 4 | **유료와 경쟁** | 🟠 높음 | 16문항이 이미 꽤 충분한 진단을 제공하면 "유료 42문항까지 할 필요 있나?"라는 의문 |

## 2. 제안된 7문항 분석

### 구조

| 카테고리 | 질문 수 | 커버 영역 |
|---------|--------|----------|
| 정체성 (identity) | Q1, Q7 | 직함 없는 자기 정의, 핵심 메시지 |
| 강점·가치 (strengths) | Q2, Q3 | 자랑스러운 순간, 자연스러운 강점 |
| 타깃 (target) | Q4, Q5 | 자연 권위 영역, 이상적 대상 |
| 차별화 (differentiation) | Q6 | 차별점 인식 |

### 장점

| # | 장점 | 설명 |
|---|------|------|
| 1 | **완료율이 높다** | 5~8분 완료 → **70%+ 완료율** 기대. 짧아서 끝까지 하게 됨 |
| 2 | **이메일 선수집** | 시작 전에 리드 확보 → 이탈해도 이메일은 가지고 있음 |
| 3 | **갭이 자연스럽게 드러남** | 7개만으로도 "답하기 어려운 질문"이 명확히 존재 (특히 Q6, Q7) |
| 4 | **유료 전환 동기가 강하다** | "7문항으로 이 정도인데, 42문항이면?" → 자연스러운 기대감 |
| 5 | **모바일 친화적** | 짧은 폼은 스마트폰에서도 부담 없음. 5060도 카카오톡 링크로 바로 진입 가능 |

### 단점

| # | 단점 | 심각도 | 설명 |
|---|------|--------|------|
| 1 | **진단이 얕아 보일 수 있다** | 🟠 높음 | 7문항만으로 "내 경력 가치"를 판단한다? → 신뢰도 의문 |
| 2 | **결과 레포트가 뻔할 수 있다** | 🟠 높음 | 데이터가 적어 AI 분석이 일반적인 말만 할 수 있음 |
| 3 | **"채널" "스토리" 영역 누락** | 🟡 중간 | 현재 7문항에 채널 전략, 브랜드 스토리 질문이 없음 → 무료에서 보여줄 수 있는 인사이트가 줄어듦 |
| 4 | **유료와의 거리감 부족** | 🟡 중간 | 7 vs 42가 숫자만 다르면 "질문만 더 많은 건가?"로 보일 수 있음 |

## 3. 핵심 질문: "무료에서 경력 가치를 어느 정도 판단할 수 있어야 하나?"

### 유료 전환이 일어나는 심리 구조

```
[1단계] "이 정도는 알겠네" (만족)
  → 무료 진단이 너무 빈약하면 여기서 이탈 ("별 거 아니네")

[2단계] "그런데 이 부분은 모르겠다" (갈증)
  → 결과에서 "갭"이 드러나야 함. 채워지지 않은 빈칸이 보여야 함

[3단계] "이걸 채우면 나도 될 수 있겠다" (기대)
  → 유료가 그 갭을 채워준다는 확신. 잠금 섹션이 이 역할

[4단계] "지금 해야겠다" (행동)
  → CTA 클릭
```

> **결론: 1단계(만족)가 충분히 달성되어야 2~4단계로 이어진다.**
> 7문항으로 1단계를 달성할 수 있는가? → 이것이 핵심 판단 기준

## 4. 추천 방향: **7문항 + 결과 보강 전략**

### 왜 7문항인가

| 기준 | 16문항 | 7문항 | 판정 |
|------|--------|-------|------|
| **완료율** (가장 중요) | 50% 미만 예상 | 70%+ 예상 | 🏆 7문항 |
| **리드 확보** | 마지막에 수집 (이탈 시 유실) | 선수집 (95% 확보) | 🏆 7문항 |
| **진단 깊이** | 깊고 풍부 | 핵심만 커버 | 🏆 16문항 |
| **유료 전환 동기** | "이미 충분한데?" 리스크 | "더 알고 싶다" 자연스러움 | 🏆 7문항 |
| **5060 디지털 접근성** | 20분 = 부담 | 5~8분 = 가능 | 🏆 7문항 |
| **모바일 전환** | 어려움 | 자연스러움 | 🏆 7문항 |

> **완료율과 리드 확보가 모든 것의 전제조건.** 아무리 깊은 진단이어도 완료하지 않으면 의미 없음.

### "7문항인데 경력 가치를 충분히 보여주는" 전략

7문항의 약점(얕은 진단)을 보완하는 방법:

#### 전략 1: **질문 자체가 자기발견이 되도록 설계**

현재 7문항은 이미 이 원칙으로 설계되어 있음:
- Q1 "직함 없이 나를 소개" → 답하는 것만으로 "나는 직함에 의존하고 있었구나" 발견
- Q6 "차별점은?" → "모르겠다"는 답 자체가 진단 결과
- Q7 "한 문장으로?" → 못 쓰면 그것이 갭

> **7문항을 답하는 과정 자체가 이미 가치 진단**. 결과 페이지 이전에 이미 "깨달음"이 시작됨.

#### 전략 2: **결과 레포트를 4개 영역 점수 카드로 구체화**

| 영역 | 평가 기준 | 점수 표현 |
|------|----------|----------|
| 정체성 명확도 | Q1 + Q7에서 직함 의존 여부, 가치 언어 사용 여부 | 0~100점 + 한 줄 코멘트 |
| 강점 자산 인식도 | Q2 + Q3에서 구체성 수준, 3개 이상 나열 여부 | 0~100점 + 한 줄 코멘트 |
| 타깃 설계도 | Q4 + Q5에서 "모든 사람" vs "마음 상태" 구분 | 0~100점 + 한 줄 코멘트 |
| 차별화 인식도 | Q6에서 "모르겠다" vs "방법론 차별화" | 0~100점 + 한 줄 코멘트 |

> 4개 영역 × 100점 = **시각적으로 충분히 "진단받은 느낌"**

#### 전략 3: **"갭"을 정확하게 찌르는 Section 5**

```
[무료에서 보여주는 것]
✅ 당신의 정체성 명확도: 65점
✅ 당신의 강점: 이런 것들이 있음
✅ 당신이 빛나는 순간의 공통점: "성장"과 "동반"

[무료에서 발견된 갭 — 유료 전환 포인트]
⚠️ 타깃 갭: "당신이 도우려는 사람이 아직 흐릿합니다"
⚠️ 차별화 갭: "차별점이 있지만 언어가 없습니다"
⚠️ 메시지 갭: "전하고 싶은 것은 있지만 한 문장이 아닙니다"

[유료에서만 완성되는 것]
🔒 브랜드 원라이너 초안 → 한끗 코칭에서 완성
🔒 이상적 고객 페르소나 → 한끗 코칭에서 완성
```

> 이 구조면 7문항으로도 **"충분히 인상적이되, 완결되지 않는"** 무료 진단이 가능

#### 전략 4: **유형 분류로 "나를 알게 된 느낌" 강화**

| 점수 | 유형 | 배지 | 한끗 메시지 |
|------|------|------|------------|
| 0~40 | 🔍 탐색형 브랜더 | 파란색 | "방향을 찾아드립니다" |
| 40~60 | 📦 준비형 브랜더 | 초록색 | "정리해드립니다" |
| 60~80 | 🔄 전환형 브랜더 | 보라색 | "전환을 설계합니다" |
| 80+ | 🚀 실행형 브랜더 | 금색 | "완성합니다" |

> "나는 📦 준비형 브랜더구나" — 이 한 줄이 16문항 결과의 장문 설명보다 강력할 수 있음

## 5. 16문항을 유지할 경우의 개선안 (대안)

만약 16문항을 유지하고 싶다면, 반드시 아래 3가지를 변경해야 함:

| # | 변경 사항 | 이유 |
|---|----------|------|
| 1 | **이메일 선수집** (진단 시작 전) | 이탈해도 리드 확보 |
| 2 | **"Part 1: 5문항" → 중간 결과 → "Part 2: 나머지 11문항"** | 5문항만 해도 기본 결과를 볼 수 있어 완료 동기 부여 |
| 3 | **진행률 바를 "섹션 단위"로 표시** | "16문항 중 3번째"보다 "Part 1 of 3"이 덜 부담스러움 |

→ 하지만 이렇게 해도 **총 소요 시간 16~20분 문제**는 해결되지 않음

## 6. 최종 추천

### 🏆 **7문항 + 결과 보강** 방향을 추천합니다

| 근거 | 설명 |
|------|------|
| **완료율이 전환의 전제조건** | 16문항 50% 완료 × 10% 전환 = 5% vs 7문항 70% 완료 × 10% 전환 = 7% |
| **리드 확보 구조** | 이메일 선수집으로 95% 리드 확보 → 팔로업 이메일로 추가 5% 전환 가능 |
| **5060 타깃 특성** | 디지털 피로도 높음, 짧고 강력한 경험이 효과적 |
| **무료↔유료 경계가 명확** | 7문항 vs 42문항 = "맛보기 vs 풀코스" 차이가 자연스러움 |
| **결과의 질은 AI가 보완** | 7문항이어도 AI 분석이 풍부한 레포트를 생성하면 "7문항인데 이 정도?" 놀라움 |

### 핵심 성공 조건

```
1. 7문항의 결과가 "가벼운 테스트" 수준이 아니라 
   "전문 진단" 수준으로 느껴져야 한다
   → Section 1~5의 레포트 퀄리티가 핵심

2. 갭이 명확하게 드러나야 한다
   → Section 5 (진단 갭) + Section 6~7 (잠금)이 전환 동기

3. 유형 분류가 "나를 알게 된 느낌"을 줘야 한다
   → "📦 준비형 브랜더" 배지 하나가 핵심

4. 잠금 섹션이 "풀고 싶은 욕구"를 만들어야 한다
   → 블러 뒤의 텍스트가 충분히 매력적이어야 함
```
