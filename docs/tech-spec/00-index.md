## 프로젝트 개요

### 서비스 정의
한끗프로젝트는 **20~30년 경력 전문가의 경험을 시장이 이해하는 언어로 번역**하는 1:1 경력 자산화 플랫폼이다.

### 핵심 비즈니스 흐름

```
[고객 진입]
    │
    ├─ 무료 진단 (15문항) ─────────────────────→ 즉시 결과 리포트
    │       └─ 이메일 수집 → Lead DB 저장
    │
    └─ 유료 서비스 신청
            ├─ 한끗 진단 (50만원, 1주)
            ├─ 한끗 빌드 (350만원, 6주)  ────→ 코칭 플로우 (42문항)
            ├─ 한끗 론칭 (별도 문의, 3개월)          └─ AI 분석 → 자산 생성
            └─ 한끗 파트너 (별도 문의, 월 단위)

[운영자]
    └─ Admin 포털 ────→ 멤버 관리, 리드 추적, 분석 결과 검토
```

### 서비스 사용자 역할

| 역할 | 설명 | 접근 범위 |
|---|---|---|
| **Guest** | 미인증 방문자 | 랜딩, 서비스 소개, 무료 진단 |
| **Member** | 유료 서비스 수강생 | 코칭 워크스페이스, 자신의 결과 |
| **Admin** | 꿈몰다 운영진 | 전체 데이터 조회·수정, 멤버 발급 |
