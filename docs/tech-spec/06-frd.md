## C-01 — 메인 랜딩

### 기능 요구사항

**FR-C01-01**: 히어로 섹션 렌더링
- CTA 버튼 2개 표시: "경력 가치 무료 진단받기" → /diagnosis, "30분 무료 상담 신청하기" → /consultation
- 위 버튼들은 스크롤 시에도 네비게이션 바에 고정 표시

**FR-C01-02**: 네비게이션 바
- 로고 클릭 → / (홈)
- "서비스 소개" → /service
- "진행 과정" → /#process (동일 페이지 앵커 스크롤)
- "상품 안내" → /#products (동일 페이지 앵커 스크롤)
- 현재 활성 링크 = 로열블루 + font-weight:800
- 스크롤 위치에 따라 앵커 링크 활성 상태 자동 변경 (IntersectionObserver)

**FR-C01-03**: 진행 과정 섹션 (`#process`)
- 4단계 카드: 진단 → 빌드 → 론칭 → 파트너
- 각 카드에 "신청하기" CTA → /apply/{product}

**FR-C01-04**: 상품 안내 섹션 (`#products`)
- 4개 상품 카드 표시
- 한끗 빌드 카드: "핵심" 뱃지 강조
- 한끗 론칭, 한끗 파트너: 가격 "별도 문의" 표시

**FR-C01-05**: FAQ 아코디언 (8개)

**FR-C01-06**: 최종 CTA 섹션 (로열블루 배경)

### 비기능 요구사항

**NFR-C01-01**: LCP < 2.5s (히어로 이미지 최적화 필수)  
**NFR-C01-02**: CLS < 0.1 (폰트 로딩 시 FOUT 방지 → font-display:swap)

### 엣지 케이스

**EDGE-C01-01**: 브라우저 뒤로가기 시 앵커 스크롤 위치 복원 → `useScrollRestoration` 훅 적용  
**EDGE-C01-02**: 모바일에서 네비게이션 메뉴 → 햄버거 메뉴로 전환 (breakpoint: 768px)

## C-03 — 무료 진단 (핵심 기능)

### 기능 요구사항

**FR-C03-01**: 단계별 폼 렌더링 (총 9단계)
- STEP 0: 이름, 이메일, 경력연수 입력 + 개인정보 동의
- STEP 1~7: Q1~Q7 각 1문항씩
- STEP 8: 보너스 체크리스트 (Q8)
- STEP 9: 완료 화면

**FR-C03-02**: 진행률 표시
- 프로그레스 바: (현재 단계 / 8) × 100%
- 현재 문항 번호 텍스트 표시 ("Q3 / 7 진행 중")

**FR-C03-03**: 유효성 검사
- STEP 0: 이름 필수, 이메일 형식, 경력연수 선택, 동의 체크 → 미완료 시 다음 이동 차단 + 에러 메시지 표시
- STEP 1~7: 5자 이상 입력 필수 → 미달 시 다음 이동 차단

**FR-C03-04**: 실시간 저장
- 각 단계 답변은 즉시 localStorage에 저장
- 브라우저 새로고침 또는 뒤로가기 후 재진입 시 마지막 답변 복원

**FR-C03-05**: 글자 수 표시
- 각 textarea 아래 "N자" 실시간 표시

**FR-C03-06**: 제출 처리
- STEP 8 완료 → Edge Function으로 POST 전송
- 로딩 상태 표시 (버튼 비활성화 + 스피너)
- 성공 → STEP 9 표시
- 실패 → Toast 에러 메시지 + 재시도 버튼

**FR-C03-07**: 개인정보 동의
- 동의 체크박스 + 개인정보처리방침 링크 (별도 탭)
- 동의 시각(consentAt) 서버에 기록

**FR-C03-08**: 완료 화면 (STEP 9)
- 입력한 이름 표시: "{이름}님, 수고하셨습니다!"
- 입력한 이메일 표시: "결과를 {email}로 보내드립니다."
- 버튼: "진단 결과 미리보기" → /result, "무료 상담 신청" → /consultation

### 엣지 케이스

**EDGE-C03-01**: 동일 이메일 24시간 내 재제출
- 서버에서 429 RATE_LIMITED 반환
- "이미 진단을 진행하셨습니다. 결과를 {email}로 확인해주세요." 메시지 표시

**EDGE-C03-02**: 네트워크 단절 중 제출 시도
- "인터넷 연결을 확인해주세요. 답변은 저장되어 있습니다." 토스트 표시
- 온라인 복구 시 자동 재시도 (navigator.onLine 감지)

**EDGE-C03-03**: STEP 7까지 완료 후 브라우저 닫기
- localStorage에 저장된 상태로 복원 → 마지막 완료 단계로 이동

**EDGE-C03-04**: 이메일 입력 후 다음 단계에서 이메일 변경 불가 (이전 버튼으로 돌아가도 읽기 전용)

**EDGE-C03-05**: 동의 없이 제출 버튼 접근 불가 (DOM 레벨에서 disabled)

### 비기능 요구사항

**NFR-C03-01**: 각 단계 전환 애니메이션 < 200ms (CSS transition)  
**NFR-C03-02**: 모바일 키패드 표시 시 레이아웃 이탈 없음 (viewport 고정)  
**NFR-C03-03**: 제출 API 응답 timeout: 10초

## C-08~C-12 — 코칭 플로우 (Mission-Critical)

### FR-C08-01: 코칭 대시보드
- 멤버 인증 필수 (미인증 → /login 리다이렉트)
- 현재 세션 상태 표시 (진행률, 답변 완료 문항 수 / 42)
- 상태별 CTA: in_progress → "이어서 작성", submitted → "검토 중", analyzed → "리포트 보기"

### FR-C09-01: 42문항 입력 인터페이스
- 문항 목록 사이드바 + 현재 문항 본문 레이아웃
- 입력 모드 전환: 텍스트 / 음성 (각 문항별 독립)
- 자동 저장: 타이핑 멈춤 1초 후 Supabase upsert
- 저장 상태 표시: "저장 중..." / "저장됨" (문항 사이드바)

### FR-C09-02: 음성 녹음
- 브라우저 마이크 권한 요청 (거부 시 텍스트 모드 전환 안내)
- 녹음 시작/중지/재녹음 컨트롤
- 녹음 파일 즉시 업로드 (POST /functions/v1/upload-voice)
- 업로드 완료 시 재생 컨트롤 표시 (VoicePlayer 컴포넌트)
- 최대 녹음 시간: 10분 / 파일 크기: 10MB 제한

**EDGE-C09-01**: 음성 업로드 실패 시 → 텍스트 입력 유지 + 재시도 버튼 표시  
**EDGE-C09-02**: 녹음 중 탭 전환 → 백그라운드 녹음 계속 (MediaRecorder 유지)  
**EDGE-C09-03**: iOS Safari 음성 포맷 → audio/mp4 (WebM 미지원) 자동 감지

### FR-C10-01: 코칭 검토 화면
- 42문항 전체 답변 일람 표시
- 미답변 문항 빨간 강조 + "작성하러 가기" 링크
- "최종 제출" 버튼 → 확인 다이얼로그 ("제출 후에는 수정할 수 없습니다") → 제출

### FR-C11-01: 분석 중 화면
- 로딩 애니메이션 + "분석이 진행 중입니다" 메시지
- 30초마다 /functions/v1/coaching-status 폴링
- analyzed 상태 수신 시 → /coaching/report 자동 이동

### FR-C12-01: 코칭 리포트
- 브랜드 프로필 섹션: 원라이너, 핵심 가치, 차별점, 타깃
- 문항별 인사이트 섹션: 패턴, 브랜딩 신호, 주요 문장
- PDF 다운로드 버튼 (브라우저 Print API 활용)
- 리포트 공유 링크 (Admin 확정 후에만 활성화)

## A-01 — Admin 포털 (핵심 운영 기능)

### FR-A01-01: 대시보드
- 오늘 신규 리드 수, 진행 중 멤버 수, 완료 세션 수 카드
- 최근 활동 피드 (리드 수신, 제출 완료, 결제 등)

### FR-A01-02: 리드 관리
- 테이블: 이름, 이메일, 소스, 상태, 생성일, 담당자
- 필터: 상태별, 소스별, 날짜 범위
- 리드 상세: 무료 진단 점수, 답변 요약, 메모 추가
- 상태 변경: new → contacted → qualified → converted / lost

### FR-A01-03: 멤버 관리
- 멤버 계정 수동 발급 (이름, 이메일, 상품, 기간)
- 발급 시 자동 이메일 발송 (초기 비밀번호 포함)
- 멤버별 진행 현황 조회

### FR-A01-04: 코칭 워크스페이스
- 멤버별 42문항 답변 전체 조회
- AI 리포트 확인 + 수정 (finalize)
- 확정 후 멤버에게 "리포트 준비 완료" 이메일 발송

## 공통 비기능 요구사항

**NFR-GLOBAL-01**: 한국어 전용 UI (다국어 고려 불필요)

**NFR-GLOBAL-02**: 타이포그래피
- 본문: Pretendard, 16px, line-height 1.7
- 제목: Pretendard Bold (weight 800)
- 코드/모노: JetBrains Mono (어드민 전용)

**NFR-GLOBAL-03**: 반응형 브레이크포인트
| 구간 | 범위 |
|---|---|
| Mobile | < 768px |
| Tablet | 768px ~ 1024px |
| Desktop | > 1024px |

**NFR-GLOBAL-04**: 접근성
- WCAG 2.1 AA 준수
- 키보드 네비게이션 지원 (Tab, Enter, Escape)
- 스크린리더 aria-label 필수 (폼 입력, 버튼)
- 색상 대비 비율 최소 4.5:1

**NFR-GLOBAL-05**: 브라우저 지원
- Chrome/Edge 최신 2버전 ✅
- Safari 16+ ✅
- Firefox 최신 버전 ✅
- IE 11 ❌ (지원 안 함)

**NFR-GLOBAL-06**: 테스트 커버리지 목표
| 레이어 | 목표 |
|---|---|
| lib/ (비즈니스 로직) | > 80% |
| store/ (상태 관리) | > 70% |
| components/ (UI) | > 50% |
| pages/ | 핵심 플로우 E2E 커버 |
